# Code of conduct

Overnote follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in issues, pull requests, reviews, and every other project space, and to anyone representing the project elsewhere.

In short:

- Be kind and patient, and assume good intent.
- Critique code and ideas, never people.
- No harassment, insults, sexualized language or imagery, or publishing anyone's private information.
- Respect a maintainer's decision to edit, hide, or remove contributions that break these rules.

## Reporting

If someone's behavior worries you, tell the maintainer privately through the contact details on the [WesleyBLDC GitHub profile](https://github.com/WesleyBLDC).
Reports are kept confidential.
The maintainer decides on a response, from a warning to a ban from the project, following the Contributor Covenant's enforcement guidelines.
