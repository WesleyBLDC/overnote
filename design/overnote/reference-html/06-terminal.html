Terminal drawer

The drawer is a normal shell that lives under the note. An agent session is just that same shell running a coding agent such as Claude Code. When you need more room, the expand button in the drawer header turns the terminal into a full-panel view; “‹ Weekend project” at top left (or ⌘⇧↩) brings you back to the note with the drawer still open.

Drawer
--bg-sunken under a --border hairline, flush with the panel. Opening it highlights the terminal button in the top bar.
Prompt
Short path in --text-tertiary, then a bold ❯ in --accent-strong. No user@host.
Colours and agents
ANSI blue and magenta → --accent-strong, bright black → --text-tertiary. Agent prompts sit in a #1C1C1F rounded block; links are white and underlined.
Expand and back
Drawer header: expand (outlined, ⌘⇧↩) and close (⌃`). Full panel: “‹ note title” on the left and collapse on the right both return to the note; the session keeps running.
