Where
Geist for the editor, UI, wordmark, website and README. Geist Mono for the terminal, code blocks, inline code and shortcuts.
Shipping
macOS doesn’t include Geist, so bundle the variable font files in the app (OFL licence). SF Pro and SF Mono are the fallbacks in every stack.
Tracking
Tighten as size grows: 0 at body size, −1% at 20 pt, −2% at 28 pt, −4.5% for the wordmark. Uppercase labels get +6%.
