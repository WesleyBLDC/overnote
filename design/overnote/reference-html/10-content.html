Spacing
12 pt between blocks, 20 pt before a heading, list indent 20 pt per level. Note padding 28 pt each side.
Colour
Only the theme tokens: --code background, --text-tertiary for done items, a 22% bar for quotes, --success and --warning for code and table accents.
